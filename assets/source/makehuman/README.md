# MakeHuman source data (CC0)

Packed by `scripts/pack_makehuman.py` from the MakeHuman repository
(https://github.com/makehumancommunity/makehuman, `makehuman/data`).
The base mesh, targets, skeleton and weights were released under **CC0 1.0** by the
MakeHuman project (see the headers inside the files). No attribution is required;
we credit the project anyway.

| file | content |
|---|---|
| `base.obj.gz` | base body mesh (19,158 vertices incl. helper geometry; units: decimetres, +Y up, +Z front) |
| `targets.bin.gz` | curated morph targets (macro: gender × age × muscle × weight, ethnicity, height, proportions, breast; plus ~230 face/body detail targets), int16-quantised sparse deltas |
| `default.mhskel.gz` | MakeHuman default skeleton (163 bones, joints defined by helper-vertex centroids) |
| `default_weights.mhw.gz` | skin weights for that skeleton |

Everything visible in the game (skin, faces, hair, clothing, props, rig, animation) is generated by
`characters/` on top of this data; the mesh itself is never shipped unmodified.
